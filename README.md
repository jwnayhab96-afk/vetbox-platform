# فيت بوكس — VetBox Platform
## منظومة الرعاية البيطرية المتكاملة في مصر | Production-Ready Arabic-First Veterinary Care Platform

فيت بوكس (VetBox) هي منصة وتطبيق ويب متكامل يربط بين مربي الحيوانات الأليفة والمواشي والأطباء والعيادات والمستشفيات البيطرية المعتمدة في مصر، ويوفر لكل حيوان جواز سفر رقمي وملفاً طبياً يرافقه طوال حياته.

---

### 🌟 المزايا والقدرات المنجزة في النظام (Implemented Features)

1. **تصميم احترافي من الدرجة الأولى (Medical Health-Tech UI/UX):**
   - هوية بصرية مستوحاة من أخضر الغابات العميق (`#164e3f`)، التيل المصقول، وألوان تحذيرية هادئة للتذكيرات والمواعيد.
   - دعم كامل ودقيق للكتابة والاتجاه العربي من اليمين لليسار (`dir="rtl"` و `lang="ar"`).
   - خط **IBM Plex Sans Arabic** لضمان وضوح وقراءة مريحة للمصطلحات الطبية والأرقام العربية.
   - تجاوب فائق على كافة الشاشات (الهواتف المحمولة 360px - 390px، الأجهزة اللوحية، والشاشات الكبيرة).

2. **أدوار المستخدمين والصلاحيات (Role-Based Access Control):**
   - **المربي (Pet Owner):** إدارة الحيوانات، استعراض السجل الطبي، طلب ربط طبيب معتمد، تتبع التطعيمات والأدوية، تسجيل الملاحظات الصحية.
   - **الطبيب البيطري (Veterinarian):** إدارة المرضى المصرح لهم فقط، تسجيل الكشوفات السريرية، توثيق التطعيمات، وضع الخطط الوقائية، اعتماد ترخيص النقابة.
   - **مشرف المنصة (Administrator):** مراجعة وتدقيق طابور تراخيص الأطباء، إدارة المنشآت والعيادات، استعراض سجلات الرقابة الأمنية (Audit Trail).

3. **جواز السفر الطبي الرقمي والملف الصحي (Digital Pet Passport):**
   - دعم شامل لكافة الفصائل: كلاب، قطط، خيول، طيور، أرانب، أبقار/عجول، أغنام، وماعز.
   - دعم تاريخ الميلاد الدقيق أو السن التقديري بالشهور.
   - توثيق المؤشرات الحيوية: درجة الحرارة، النبض، والتنفس.
   - الفصل الصارم بين الكشوفات السريرية المعتمدة وملاحظات المربي.

4. **التطعيمات والمواعيد والتذكيرات (Vaccinations & Reminders):**
   - فصل مفهومي وتقني صارم بين:
     1. تطعيم تم إعطاؤه وتوثيقه فعلياً بواسطة طبيب برقم التشغيلة (Batch) والشركة المصنعة.
     2. خطة تطعيمات مستقبلية موصى بها من الطبيب.
     3. تنبيه وتذكير موعد في النظام قابل للإكمال.

5. **دليل الاكتشاف والبحث الجغرافي (Clinics & Veterinarians Discovery):**
   - دليل العيادات والمستشفيات البيطرية في القاهرة، الجيزة، والإسكندرية مع فلترة طوارئ 24 ساعة.
   - دليل الأطباء البيطريين وتخصصات الجراحة، الباطنة، والجلدية.
   - مكتبة وموسوعة المعرفة البيطرية بمقالات موثقة ومراجعة طبياً.

### 📂 بنية المسارات والصفحات (Application Architecture & Routes)

#### الصفحات العامة:
- `/` — الصفحة الرئيسية (Landing Page)
- `/clinics` — دليل العيادات والمستشفيات
- `/clinics/[id]` — تفاصيل المستشفى والخدمات
- `/veterinarians` — دليل الأطباء المعتمدين
- `/veterinarians/[id]` — الملف المهني للطبيب وطلب الربط
- `/learn` — موسوعة المعرفة البيطرية
- `/learn/[slug]` — تفاصيل المقال والمراجع الطبية
- `/about` — عن المنصة ورؤيتها
- `/privacy` — سياسة الخصوصية
- `/terms` — شروط الاستخدام

#### بوابات المصادقة:
- `/auth/login` — تسجيل الدخول (مع خاصية الدخول التجريبي الفوري بنقرة واحدة)
- `/auth/register` — إنشاء حساب جديد (مربي أو طبيب)
- `/auth/forgot-password` — استعادة كلمة المرور
- `/auth/callback` — استكمال مصادقة Supabase

#### بوابة المربي (Owner Portal):
- `/owner/dashboard` — نظرة عامة وتنبيهات
- `/owner/pets` — دفتر الحيوانات
- `/owner/pets/new` — معالج إضافة حيوان جديد (4 خطوات)
- `/owner/pets/[id]` — الملف الطبي والجواز الصحي الكامل
- `/owner/reminders` — جدول المواعيد والتطعيمات
- `/owner/veterinarians` — الأطباء المربوطين
- `/owner/notifications` — مركز الإشعارات
- `/owner/settings` — إعدادات الحساب

#### بوابة الطبيب البيطري (Veterinarian Portal):
- `/veterinarian/dashboard` — لوحة الطبيب وحالة الاعتماد
- `/veterinarian/patients` — قائمة المرضى المصرح لهم
- `/veterinarian/patients/[petId]` — السجل الطبي السريري للمريض
- `/veterinarian/visits/new` — تسجيل كشف سريري معتمد
- `/veterinarian/connection-requests` — طلبات الربط وإدارتها
- `/veterinarian/verification` — اعتماد ترخيص النقابة
- `/veterinarian/profile` — الملف المهني وسعر الكشف
- `/veterinarian/settings` — الإعدادات

#### بوابة الإدارة والرقابة (Admin Portal):
- `/admin/dashboard` — نظرة عامة وطابور الاعتماد
- `/admin/veterinarians` — مراجعة وتوثيق الأطباء
- `/admin/users` — إدارة الحسابات
- `/admin/clinics` — المنشآت والعيادات
- `/admin/articles` — المحتوى التثقيفي
- `/admin/reports` — سجلات التدقيق (Audit Logs)
- `/admin/settings` — إعدادات المنظومة

### 🗄️ قاعدة البيانات وسياسات الأمان (PostgreSQL & Supabase RLS)

تتضمن مجلدات المشروع ما يلي:
1. `supabase/migrations/20240101000000_vetbox_core_schema.sql`:
   - جداول `profiles`, `veterinarian_profiles`, `clinics`, `clinic_memberships`, `pets`, `pet_vet_links`, `medical_visits`, `medical_entries`, `vaccination_records`, `vaccination_plans`, `medications`, `reminders`, `attachments`, `articles`, `notifications`, `audit_logs`.
   - دوال الأمان: `public.current_user_role()`, `public.has_pet_access(target_pet_id)`.
   - سياسات الأمان على مستوى الصف (RLS) تمنع أي طبيب من رؤية حيوان إلا بعد موافقة المربي الصريحة، وتمنع المربي من ادعاء دور الطبيب أو تزوير تشخيص معتمد.
2. `supabase/seed.sql`:
   - بيانات تجريبية واقعية للسوق المصري بمحافظات القاهرة والجيزة والإسكندرية لكافة الفصائل.

### 🚀 خطوات التشغيل المحلي (Getting Started Locally)

1. **تثبيت الحزم (Install Dependencies):**
   ```bash
   npm install
   ```

2. **إعداد المتغيرات البيئية (Environment Variables):**
   انسخ ملف `.env.example` إلى `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
   التطبيق يحتاج مشروع Supabase حقيقياً، ولا يوفر دخولاً تجريبياً أو حفظاً محلياً. لا تضف مفتاح Service Role إلى متغيرات `NEXT_PUBLIC_*` أو إلى كود المتصفح.

3. **تجهيز قاعدة البيانات:**
   ```bash
   npx supabase link --project-ref <project-ref>
   npx supabase db push
   ```
   يطبق ذلك ملفات `supabase/migrations`، ومنها ترحيل تقوية الصلاحيات وإنشاء جدول الوصفات. ملف `supabase/seed.sql` يحتوي بيانات تدريبية خيالية؛ استخدمه في التطوير فقط ولا تشغله في الإنتاج. أنشئ حساب المدير وامنحه دور `admin` من لوحة Supabase عبر وصول إداري موثوق.

4. **تشغيل الاختبارات الآلية (Run Tests):**
   ```bash
   npm test
   ```

5. **بدء خادم التطوير (Start Dev Server):**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

6. **بناء الإنتاج (Production Build):**
   ```bash
   npm run build
   npm run start
   ```
